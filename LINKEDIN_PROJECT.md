## Project Description (Full — LinkedIn allows up to 2000 chars)

GapForge is a production-grade research intelligence platform I built from scratch — 95+ features, 126 API routes, 93 pages, deployed on Vercel with a live user base.

**The problem:** Researchers spend 6–18 months doing manual literature reviews before finding a viable research direction. GapForge reduces this to minutes.

**What it does:**
— Queries Semantic Scholar, arXiv, PubMed, OpenAlex, Crossref, bioRxiv, CORE, DOAJ, and NASA ADS simultaneously
— Uses Azure OpenAI GPT-4o to detect 6 types of research gaps, ranked by confidence, novelty, and feasibility with real citations
— Generates complete grant proposals (NIH R01, NSF, EU Horizon), full research papers section-by-section, peer review simulations, policy briefs, and systematic reviews
— Weekly personalized Gap Drops delivered to researchers' inboxes every Friday
— Community features: leaderboard, challenges, collaboration matchmaking, gap battles

**Tech stack:** Next.js 16 (App Router), TypeScript, Neon Postgres, Upstash Redis, NextAuth v4, Azure OpenAI GPT-4o (Microsoft for Startups approved), Groq/Gemini/Claude fallbacks, Resend email, Paystack + Flutterwave (GHS payments), Vercel Cron (5 automated jobs), Framer Motion.

**Business:** GHS pricing for Ghana market (Starter: GHS118, Pro: GHS236, Team: GHS472). Microsoft for Startups approved ($1,000 Azure credits).

Built as a solo full-stack project — architecture, design, backend, frontend, payments, security hardening, email automation, and deployment entirely by me.
